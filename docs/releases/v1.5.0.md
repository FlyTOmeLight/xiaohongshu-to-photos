重新设计工具栏弹窗，按选图、确认保存位置和查看结果组织操作。

- 固定 420 × 600 弹窗，三列方形图片，底部保存按钮始终可见。
- 每张图可独立放大查看静态预览，放大不改变选择。
- 保存位置改为底部面板，支持 macOS「照片」相簿和本地文件夹，确认后记住位置。
- 逐图显示成功、失败和页面版本，详细原因单独查看；重试后保留此前成功图片的标记。
- 保存记录独立成页，按日期分组，显示缩略图、保存位置、媒体编号和原笔记链接；清除前确认。
- README 更新操作说明、新界面截图和已确认的可点击设计稿。
