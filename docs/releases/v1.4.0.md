本版完成 #10–#16 的七项改进：

- 配对后使用系统 PHLivePhoto 验证实况资源；增加真实媒体验收。
- 可单独重试失败图片，保留原编号和保存目标。
- 原图候选不可用时提示已使用页面版本。
- 记住常用相簿和本地文件夹，浏览器重启后仍保留。
- 下载改为分块写入；支持停止任务并保留已保存内容。
- 导出 source.json 来源记录；增加可清除的本地保存历史和重复提示。
- 安装包内置 Apple Silicon / Intel 通用实况组件，无需 Apple 开发工具。

需要 macOS 13+、Chrome 109+、Python 3.10+。下载本页的 `xiaohongshu-to-photos-1.4.0.zip`，GitHub 自动生成的 Source code 包不含预编译组件。

更新时重新运行 `native-host/install.command`，再到 `chrome://extensions` 重新加载扩展。本版连接器协议升级为 3。旧连接器会提示更新。

实况资源已覆盖真实图像、视频及系统加载检查。个人 Photos 图库中的按住播放和 iCloud 同步仍需实际验收。Intel 与 Apple Silicon 分别在 CI 中运行安装和实况加载测试。
