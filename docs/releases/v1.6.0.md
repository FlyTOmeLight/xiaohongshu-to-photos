支持 X (Twitter) 帖子与长文章的图片、GIF 与 MP4 视频保存。

- 新增 X/Twitter 平台支持：解析推文与文章中的原图、GIF 动图及 MP4 视频。
- 网页 blob 播放器与全屏图片浮层自动通过公开 Syndication 数据提取最高码率 MP4 直链与原图。
- 过滤平台默认宣传占位图，解决全屏大图模式（`/photo/1`）下 DOM 隔离和预览异常问题。
- 本机连接器新增 X 域名白名单与媒体类型/签名安全校验，支持独立视频导入「照片」图库或导出到本地文件夹。
